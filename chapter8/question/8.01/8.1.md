# 研究課題8.1
## 課題内容
**親か子か** forkの戻り値を使えば、プロセスは自分が親プロセスか子プロセスかを判断できる。
プロセスの親子を見分けるために他に使えるテクニックは何か。

## pidを記録しておくことで判断できる。
forkを呼び出す前にgetpidで親プロセスのpidを取得しておき、
その後にpidを比較することによって、親プロセスか子プロセスかの違いを判断できる。

### コード
```

/* forkdemo4.c -
 * fork()の戻り値を使って、自分が親か子かを判断するにはどうすればよいかを示す。
 */

#include <stdio.h>
#include <sys/wait.h>
#include <unistd.h>

int main(void) {
  int fork_rv;

  printf("Before : my pid is %d \n", getpid());
  int parentpid = getpid();
  fork_rv = fork();

  if (parentpid == getpid()) {
    printf("I am the parent. my child is %d \n", fork_rv);
    wait(NULL);
  } else {
    printf("I am the child. my pid is %d \n", getpid());
  }
}

```

### 実行結果
```
$ ./forkdemo
Before : my pid is 32517 
I am the parent. my child is 32518 
I am the child. my pid is 32518 

```

### この方法の問題点
forkの戻り値を使わずともpidの比較で親か子かの判別は可能であるが、
forkの戻り値は-1だったときのエラー処理にも使うことができるので、
forkの戻り値で判断したほうが合理的と思われる。
